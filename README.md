## About

This research repository records addresses, symbols, type layouts,
relationships, and qualified behavior from the Xbox 360 guest program. It is an
analysis catalog, not a runtime or build dependency.

Retail binaries, decrypted images, Ghidra projects, raw decompiler output, and
generated code remain outside the tracked tree.
